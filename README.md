# Double Pendulum Simulation

A numerical simulation and animation of a chaotic double pendulum system, built with Python, NumPy, and Matplotlib.

## Overview

This project simulates the motion of a **double pendulum** — two pendulums attached end to end — a classic example of a chaotic dynamical system. The equations of motion are derived from Lagrangian mechanics and integrated numerically over time, then rendered as a live animation showing the pendulum's motion along with a fading trace of its path.

## Repository Contents

| File | Description |
|---|---|
| `double_pendulum.py` | Main script — simulates the double pendulum's motion and animates it |
| `double_pendulum_data.csv` | Sample output dataset (time, angles, and Cartesian positions) generated by the script |

## How It Works

### 1. Physical Model
The system consists of two point masses (`M1`, `M2`) connected by two rigid, massless rods (`L1`, `L2`), swinging under gravity (`G`). The equations of motion are the standard nonlinear, coupled second-order ODEs for a double pendulum, derived from the Lagrangian of the system.

### 2. Numerical Integration
- The state vector is `[θ1, ω1, θ2, ω2]` — the angles and angular velocities of both pendulum arms.
- The script integrates the equations of motion using a simple **Euler method** with a fixed timestep (`dt = 0.01 s`) over a configurable simulation duration (`t_stop = 10 s`).
- A commented-out line shows how to swap in `scipy.integrate.solve_ivp` for a more accurate (adaptive) integrator.

### 3. Coordinate Conversion
Angular positions (`θ1`, `θ2`) are converted into Cartesian coordinates (`x1, y1`, `x2, y2`) for both pendulum bobs, used for plotting and animation.

### 4. Dataset Export (optional)
The simulation results (`t`, `theta1`, `theta2`, `x1`, `y1`, `x2`, `y2`) can be saved to `double_pendulum_data.csv` — this line is currently commented out in the script and can be re-enabled as needed. Resampling to a different output rate than the integration step is also supported via row-slicing.

### 5. Animation
Using `matplotlib.animation.FuncAnimation`, the script renders:
- The two pendulum arms as connected line segments
- A fading trace of the second bob's recent trajectory (limited to the last `history_len` points)
- A live time counter

The animation can optionally be saved as an `.mp4` or `.gif` instead of (or in addition to) being displayed live.

## Usage

```bash
python double_pendulum.py
```

This opens a live Matplotlib animation window showing the pendulum's motion for 10 seconds.

### Configuration
Key parameters can be edited at the top of the script:

```python
G = 9.8       # gravity (m/s^2)
L1 = 1.0      # length of pendulum 1 (m)
L2 = 1.0      # length of pendulum 2 (m)
M1 = 5.0      # mass of pendulum 1 (kg)
M2 = 5.0      # mass of pendulum 2 (kg)
t_stop = 10   # simulation duration (s)
th1, th2 = 90.0, 90.0   # initial angles (degrees)
w1, w2 = 0.0, 0.0       # initial angular velocities (deg/s)
```

To export the dataset, uncomment:

```python
data.to_csv('double_pendulum_data.csv', index=False)
```

To save the animation instead of displaying it live, uncomment one of:

```python
ani.save('double_pendulum.mp4', fps=int(1/dt))
ani.save('double_pendulum.gif', writer='pillow', fps=int(1/dt))
```

## Notes & Limitations

- Euler's method is simple but not energy-conserving over long simulation times — for higher accuracy, use `scipy.integrate.solve_ivp` (see the commented alternative in the script).
- The double pendulum is a chaotic system — tiny changes in initial conditions (`th1`, `th2`, `w1`, `w2`) lead to drastically different trajectories.
- Saving `.mp4` output requires `ffmpeg` installed and available on your system PATH; `.gif` output requires the `pillow` writer.
